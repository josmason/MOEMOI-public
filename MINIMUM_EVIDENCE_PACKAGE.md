# MOEMOI — Minimum Evidence Package

*A one-page evaluation aid for time-pressed researchers. Read this before the preprint. The preprint has the full derivations; this has the minimum you need to decide whether the full read is worth your time.*

## The core claim (one sentence)

All intelligent systems — whether a biological organism, a human practitioner, an organisation, or an AI — improve by running one shared recursive loop: **Experience → Understand → Define → Prioritise → Plan → Ensure Execution** (the Intelligence Process, IP). The quality of execution at each substep predicts the quality of outcomes, holding constraints constant.

**Epistemic status:** Working assumption, graded with 163 falsifiable sub-claims (137 sequentially numbered C1–C142 with 5 legacy gaps; 26 named aliases). Not asserted as metaphysically certain.

## Two strongest empirical anchors

**Anchor 1 — 21-framework structural convergence (N=21; AI-originated, external validation ongoing).**
OODA (Boyd), PDCA (Shewhart/Deming), the scientific method (Bacon/Popper), CBT's formulation-intervention loop, Toyota Coaching Kata, active inference (Friston), the Goedel Machine (Schmidhuber), and 14 additional frameworks each map onto the IP's six substeps. The convergence is not superficial analogy — each framework independently names the same substeps in the same sequence, with the same failure modes when substeps are skipped. The structural derivation (preprint Section 3) shows this mapping is mathematically necessary given the definition of an intelligent system that improves recursively. The mapping is falsifiable: a rigorous framework that achieves better outcomes WITHOUT one of the six substeps would disconfirm the universality claim (kill-line: one OECD-validated coaching framework scoring STRONG at all IP rubric criteria without a distinct Prioritise substep).

**Anchor 2 — N=9 controlled framework comparisons, rubric-scored — 9 of the 21-framework set above (AI-originated, ADOPTED 0.75-0.78).**
A blind rubric audit of 9 practitioner frameworks (including the 21-framework set above) scored each framework against a 6-substep IP rubric. Two empirical findings with ADOPTED status:
- Frameworks naming "practitioner redundancy" as their PRIMARY success criterion scored STRONG on Become-Capable (C102, ADOPTED 0.75; 4/9 STRONG, 5/9 MODERATE). Mechanism: when practitioner redundancy is primary, scaffolding fading is criterion-entailed, not discretionary (Wood, Bruner, and Ross 1976).
- Only a per-cycle mandatory resource-elicitation question (not role presence) produces STRONG scores on the Resource substep across the audit (C101, ADOPTED 0.78; 8/9 PARTIAL without it, 1/9 STRONG with it — Toyota Coaching Kata).
These two empirical findings are independently testable with new framework samples. Kill-line for C101: a new N≥5 audit finds ≥3/5 STRONG Resource scores WITHOUT a mandatory per-cycle elicitation question.

## One falsification criterion (the main one)

The single most powerful falsification: **IP-completeness scores fail to predict practitioner outcomes in a well-powered prospective study (N≥50, multi-domain, pre-registered).**

The n=1 pilot (ongoing, August 2026 first checkpoint) tests this at the individual level: does running more substeps per day correlate with better outcomes? The hypothesis is pre-registered and the kill-line is explicit: if a 12-week analysis finds r < 0.20 between daily IP-completeness score and a composite outcome measure (task completion, relationship quality, subjective wellbeing), the framework's operational core requires revision.

A group-level study comparing high-IP-completeness practitioners vs controls on any measurable outcome domain (health, productivity, relationship satisfaction) would be more powerful. The framework design is built so that this study IS possible with current instruments.

## About the claims register

The claims register is not a list of assertions. Each claim has:
- A status tier: HYPOTHESIS (initial), CANDIDATE (evidence threshold met), ADOPTED (kill-line threshold met), ARCHIVED (superseded).
- A confidence score (0.0-1.0) with a named empirical basis.
- A kill-line: a specific result that would force a downgrade.

As of v0.22: 80 claims are ADOPTED. 56 are CANDIDATE. 22 are HYPOTHESIS. 4 are HELD (pending Gemini second-pass or greenlight). The register is designed so that finding evidence against a claim is a contribution (it tightens the framework), not an attack.
